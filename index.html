HTML steht für HyperText Markup Language.

Alle Webseiten benutzen HTML um Text und andere coole Sachen zu zeigen.

HTML ist keine richtige Programmiersprache sondern eher ein Format um dinge im Browser anzuzeigen.

HTML ist aber nicht das einzige was Webseiten zum funktionieren bringt, CSS ist quasi die Designanleitung
und JavaScript ist eine vollständige Programmiersprache die für die Logik hinter Webseiten verantwortlich ist.

Weil du wahrscheinlich kein bock darauf hast ewig erstmal die Grundsätze zu lernen ist hier schonmal der Link zum HTML Editor
